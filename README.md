"# Ezhire_API_Automation_Postman" 
🚀 EZHIRE Mobile App - API Automation for Booking

I have automated the mobile app booking process for EZHIRE Rent a Car, enabling booking creation through multiple payment methods:
✅ Card
✅ Wallet
✅ Partial Payments

These bookings support various durations:
📅 Daily | 📆 Weekly | 📅 Monthly

🔹 A Postman collection is set up with multiple environments for seamless testing.
🔹 After booking creation, the Booking ID and other details are logged to the console for tracking.


Run Collections to create booking.
